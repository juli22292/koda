## Koda 0.2.2

- Koda prüft beim Start und danach automatisch jede Minute auf Updates. Das Update-Symbol bleibt links neben „Minimieren“; Download und Neustart werden weiterhin von dir ausgelöst.
- Neue, ruhige Oberfläche mit neutralem Dunkelmodus, kompakter Seitenleiste, letzten Chats und einem zentralen Eingabefeld.
- Oben zwischen Chat und Code wechseln: Chat hilft beim Schreiben, Fragen und Ideen; Code arbeitet mit deinen Projektdateien. Der lesende Fragen-Modus bleibt verfügbar.
- Suche, Projekte und eigene Anweisungen sind direkt über die Seitenleiste erreichbar. Modell und Projekt lassen sich unter dem Eingabefeld wählen.
- Eigene API-Keys, vorhandene Chats und die gewählte Darstellung bleiben erhalten. Die bereits entfernten Hinweis- und Fußzeilen bleiben ausgeblendet.
- Die Release-Werkzeuge ändern keine Repository-Sichtbarkeit. Das Quellcode-Repository bleibt öffentlich.

### Installation

In einer bereits installierten Version unter **Einstellungen → Über Koda → Nach Updates suchen** prüfen und anschließend das Update-Symbol links neben „Minimieren“ verwenden. Alternativ die Datei **Koda-Setup-0.2.2-x64.exe** herunterladen und starten. Einstellungen, eigene API-Keys und Chats bleiben erhalten. Die Prüfung jede Minute gilt ab der Installation von 0.2.2.

Der Installer ist derzeit nicht mit einem Windows-Herausgeberzertifikat signiert.
